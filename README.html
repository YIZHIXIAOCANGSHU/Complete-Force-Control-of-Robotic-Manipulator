AM-D02 七轴机械臂
Pinocchio 控制与仿真系统

基于 Pinocchio 刚性动力学库（v3.9）的 AM-D02 七轴工业机械臂控制系统。 支持 MuJoCo 联合仿真、USB2FDCAN 实机控制、蒙特卡罗末端范围分析、 CAN 总线反馈镜像仿真，以及惯性参数辨识（质量 / 质心 / 对角线惯量）。

项目已将原先 stm32_code/ 中的全部 C 语言计算迁移至 Pinocchio， 不再依赖任何 C 编译环节。运行脚本 bash run.sh 一键启动。

参数辨识

辨识目标

对每个关节连杆辨识 7 个基惯性参数：质量 (1)、质心 xyz (3)、对角线惯量 Ixx/Iyy/Izz (3)。 共 7×7 = 49 个参数。

算法流程

  1. 激励轨迹 — 有限项 Fourier 级数生成平滑关节轨迹， qi(t) = q₀i + Σk ai,k/(kω) sin(kωt) − bi,k/(kω) cos(kωt)
  2. 数据采集 — Sim: MuJoCo 逆动力学获取真实力矩 (mj_inverse)。 Real: USB2FDCAN 采集关节反馈，数值微分估计 qd/qdd
  3. 回归矩阵 — Pinocchio computeJointTorqueRegressor() 提取 mass / COM / 对角线惯量对应列
  4. 最小二乘 — π̂ = (YᵀY + λI)⁻¹ Yᵀ τ，附加正定约束

可视化

  • Sim 模式: MuJoCo 被动窗口实时显示机械臂执行激励轨迹； Rerun 窗口展示 q/qd/qdd 时间曲线和力矩对比
  • Real 模式: Rerun 窗口展示采集数据时间曲线
  • 终端: 辨识完成后打印结构化中文结果表格和 URDF 真值对比

关键技术细节

坐标系

URDF 的 world_to_base 帧定义了从世界系到机械臂基座的变换 (1m Z 偏移 + 120° 旋转)。 Pinocchio FK 在世界系中计算，通过 actInv(world_to_base) 转换到 body frame， 与原有 C 代码输出完全对齐（验证误差 < 1e-6 m / < 0.6°）。

Joint 3 连续关节

ArmLfourth_Joint 在 URDF 中定义为无界连续旋转关节 (nq=2, nv=1)，使用 cos/sin 参数化。 通过 q7_to_q8() / q8_to_q7() 在 7 元组 C-style 关节角和 8 元组 Pinocchio 配置向量间透明转换。

控制律

完整复刻原 stm32_code 中的控制逻辑：Kalman 速度滤波 → FK → 目标 sanitization → 直线路径插值 + 四元数 slerp → DLS IK (关节限位, λ 阻尼) → 非线性效应补偿 (pin.nonLinearEffects) → 等效力矩合成 (kp·e_pos + kd·e_vel + tau_ff)。

迁移历史

本项目原先依赖 stm32_code/ (~800 行 C, RBDL‑Lite RNEA) 和 c_interface/ (二进制子进程通信)。现已全部删除， 计算完全由 Pinocchio 库接管。串口目标转发链路也已移除， 实机控制仅保留 USB2FDCAN 通道。
